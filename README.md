# 🎯 DreamList

O **DreamList** é um aplicativo mobile criado para tornar o planejamento de atividades e a organização de listas de desejos mais dinâmico, prático e divertido.

---

## ✨ Funcionalidades

- ➕ **Criar:** Adicionar novos desejos e metas.
- 📋 **Listar:** Visualizar todos os itens cadastrados de forma simples.
- ✏️ **Atualizar:** Editar as informações e detalhes dos desejos.
- ✅ **Concluir:** Marcar metas e atividades como realizadas.
- 🗑️ **Excluir:** Remover itens da lista.

---

## 🛠️ Tecnologias Utilizadas

- **React Native**
- **JavaScript**

---

## 🚀 Como Executar o Projeto

```bash
# 1. Clone o repositório
$ git clone [https://github.com/seu-usuario/dreamlist.git](https://github.com/seu-usuario/dreamlist.git)

# 2. Entre na pasta do projeto
$ cd dreamlist

# 3. Instale as dependências
$ npm install

# 4. Inicie o aplicativo
$ npx expo start
```
